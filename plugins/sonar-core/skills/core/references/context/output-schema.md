Baca file ini sebelum generate output di Fase 3, baik dari Full Mode maupun Quick Mode.

## Output 1 — context_profile.json

Schema ini **terkunci** — jangan ubah nama key, nesting, atau tipe data-nya tanpa alasan kuat, karena kelima project S.O.N.A.R (Discovery, Strategy, Production, Optimization, Technical) membaca struktur ini apa adanya. Kalau memang perlu berubah, itu perubahan besar dan masuk kategori major version bump (lihat bagian Versioning di SKILL.md).

**Perubahan di C.O.R.E v2.0 (aditif, tidak merusak file v1.1):**
- Tambah blok top-level `seo` (dijelaskan di `seo-block.md`). Semua key v1.1 tetap sama.
- `_meta.created_by` jadi `C.O.R.E v2.0`, tambah `_meta.schema_version` = `2.0`.
- Flag lama dipertahankan supaya file lama tetap terbaca, dengan arti baru: `ping_ready` = siap untuk Discovery, `sonar_ready` = siap untuk Strategy, `helix_ready` = siap untuk Production (NEXUS).
- File v1.1 yang belum punya blok `seo` tetap valid. Isi blok `seo` saat file itu pertama kali dipakai untuk kerja SEO, lalu bump versi profile (minor).

## Ecosystem Mode Mapping

Auto-detect `_meta.ecosystem_mode` dari `general_overview.industry` dan `product_details`, lalu **tampilkan deteksinya ke user untuk dikonfirmasi** — jangan diam-diam diasumsikan benar, karena satu industri bisa masuk beberapa mode tergantung model bisnisnya.

| Industri / Produk | P.I.N.G Mode | `ecosystem_mode` value |
|---|---|---|
| E-commerce, distributor, produk fisik | MODE 1 — Product Catalogue | `MODE_1_PRODUCT_CATALOGUE` |
| Konsultan, system integrator, B2B service | MODE 2 — Solution Provider | `MODE_2_SOLUTION_PROVIDER` |
| Software, SaaS, platform berbayar | MODE 3 — SaaS / Software | `MODE_3_SAAS_SOFTWARE` |
| Consumer brand, F&B, lifestyle | MODE 4 — Brand / Content | `MODE_4_BRAND_CONTENT` |
| Manufaktur, pabrik, custom production | MODE 5 — Packaging / Manufacturing | `MODE_5_PACKAGING_MANUFACTURING` |

Kalau tidak ada yang cocok persis, pilih yang paling dekat dan jelaskan alasannya ke user saat konfirmasi.
